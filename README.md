# 아침 5분 묵상

순종·감사·겸손으로 하루를 시작하는 개인용 PWA입니다. 기록은 **아이폰에만** 보관하고, 학교 PC에서는 글을 써서 아이폰으로 보내기만 합니다.

```
오늘의 말씀 → 묵상 질문 → 감사·다짐·기도 → 저장 (다짐은 첫 화면에 하루 종일)
```

## 바로 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # 날짜·주제 순환·암호화·병합 테스트
npm run build    # dist/ 에 배포 파일 생성
```

## 구조

| 파일 | 하는 일 |
|---|---|
| `src/data/verses.ts` | 주제별 말씀 60구절 (장·절과 찾기용 요약만, 본문 없음) |
| `src/data/questions.ts` | 묵상 질문 30개 |
| `src/lib/today.ts` | 날짜 → 오늘의 주제·말씀·질문 (순종→감사→겸손 하루씩 순환) |
| `src/lib/db.ts` | 기기 안 저장소(IndexedDB, Dexie), 백업 내보내기/가져오기 |
| `src/lib/device.ts` | 이 기기의 역할: 내 아이폰 / 학교 PC |
| `src/lib/crypto.ts` | 아이폰 자물쇠(RSA 공개키)로 잠그고 열쇠(개인키)로 여는 암호화 |
| `src/lib/inbox.ts` | Supabase 우편함: 학교 PC가 넣고, 아이폰이 꺼낸 뒤 지움 |
| `supabase/schema.sql` | 우편함 표 + RLS |

## 말씀 본문

60구절 모두 **개역한글**(1961, 대한성서공회) 본문이 들어 있습니다. 개역한글은 저작권 보호기간이 끝난 것으로 알려진 번역본입니다.

- 출처: npm 패키지 `@scoynim/bible` 0.1.1의 한국어 데이터. 시편 표제(`[다윗의 시]` 등)는 뺐습니다.
- 시편 92편 1~3절은 개역한글이 한 문장으로 묶어 번역한 부분이라 `시편 92:1-3`으로 표기했습니다.
- 앱의 **본문 고치기**로 다른 번역(예: 개역개정)을 적으면 내 기기와 내 계정에서만 그 본문이 보입니다.
  개역개정은 저작권이 있으니 저장소 코드에는 넣지 마세요.

## 기록은 어디에 남나: 우체통 방식

```
학교 PC ──(아이폰 자물쇠로 잠근 편지)──▶ 우편함(Supabase) ──▶ 아이폰이 열어 보관, 우편함에서 삭제
```

- **아이폰**이 자물쇠(공개키)와 열쇠(개인키)를 만듭니다. 열쇠는 아이폰 밖으로 꺼낼 수 없습니다.
- **학교 PC**는 자물쇠만 받아 글을 잠가 보냅니다. PC에는 글, 임시 글, 열쇠 무엇도 저장하지 않고,
  입력칸의 자동완성 기록도 끕니다. PC에 남는 것은 기기 역할 표시와 로그인 정보뿐이며,
  설정의 **“이 PC에서 로그아웃하고 모두 지우기”**로 그것까지 지울 수 있습니다.
- **서버**에는 아이폰이 받기 전까지 열 수 없는 암호문만 잠깐 머뭅니다.
- 두 기기 설정에 보이는 **자물쇠 지문**이 같은지 한 번 확인하세요.

> 기록이 아이폰에만 있으므로, 아이폰을 바꾸거나 Safari 데이터를 지우면 사라집니다.
> 가끔 설정 → 백업 → 내보내기로 iCloud Drive 같은 개인 공간에 백업하세요(이 파일은 암호화되지 않습니다).

## 우편함 켜기

1. [supabase.com](https://supabase.com)에서 새 프로젝트 만들기 (무료 플랜으로 충분)
2. SQL Editor에 `supabase/schema.sql` 붙여 넣고 실행
3. Authentication → Sign In / Providers → **Allow new users to sign up 끄기**
4. Authentication → Users → **Add user**로 내 이메일·비밀번호 계정 직접 만들기
5. Project Settings → API에서 URL과 anon key를 복사해 배포 환경 변수에 넣기 (`.env.example` 참고)
6. 아이폰: 앱 → “내 아이폰” → 설정 → 로그인 → **우편함 준비하기**
7. 학교 PC: 앱 → “학교 PC” → 설정 → 같은 계정으로 로그인 (비밀번호 저장은 “안 함”)

## 배포 (나만 들어오게)

1. 이 폴더를 **비공개** GitHub 저장소로 올리기
2. Cloudflare Pages에서 저장소 연결 → Build command `npm run build`, Output `dist`
   → 환경 변수에 `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`
3. Cloudflare Zero Trust → Access → Applications → 배포 주소에 내 이메일만 허용하는 정책 추가
4. 아이폰 Safari에서 열기 → 공유 → **홈 화면에 추가**
5. 학교 PC Chrome/Edge에서 열기 → 주소창의 **앱 설치** 버튼
